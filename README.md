A deterministic Node 22 program (stdlib only) that writes one original funny line to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty. The line:

> I tried to ghost my gym, but it keeps texting 'we miss you' like an ex who knows my card number.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` by default. Pass an output directory to test locally:

```sh
node main.ts /tmp/out
```

The program self-checks the gate before writing (1–140 characters, one line, not only whitespace) and verifies the file by reading it back.

## Why this line

Five candidates were drafted; this one won because the twist lands on the last words and is concrete — the gym ex *literally* has your card number, so the breakup never works. Every word earns its place, it reads clearly the first time, and it is not a joke already making the rounds.

Rejected: a horoscope-stays-in-bed line (premise too familiar), a diary-starts-a-podcast line (twist good but wordy), a plants-stage-an-intervention line (cute observation, weak punch), and an alarm-clock-takes-a-break line (reversal good, punch too abstract).
